PENTING: drag folder "ssglobal" je ke Cloudflare, bukan fail ni.

ISI FOLDER
  index.html            Site ahli (FastStart & SSPC)
  admin.html            Panel admin  (kata laluan demo: admin123)
  manifest.webmanifest  Untuk "Add to Home Screen" site ahli
  admin.webmanifest     Untuk "Add to Home Screen" admin
  icons/                Ikon app (logo Emas Sri Semantan)
  favicon.ico           Ikon tab browser
  robots.txt            Sekat Google & bot AI (GPTBot, ClaudeBot, CCBot, dll.)
  _headers              Header keselamatan: noindex/noai, tak boleh di-embed dalam iframe

CARA UPLOAD KE CLOUDFLARE PAGES
  1. Cloudflare dashboard > Workers & Pages > Create > Pages > Upload assets
  2. Letak nama projek (cth: ssglobal-demo) > drag folder "ssglobal" ni > Deploy
  3. Link demo:  https://<nama-projek>.pages.dev
     Admin:      https://<nama-projek>.pages.dev/admin

LINDUNGI DEMO (DIGALAKKAN)
  - Cloudflare Zero Trust > Access: kunci link demo supaya hanya emel tertentu
    (cth emel lecturer) boleh buka. Orang lain yang dapat link takkan nampak apa-apa.
  - Hidupkan setting sekat AI bots / AI crawlers dalam Cloudflare.
  - Lepas demo siap, padam atau tutup projek Pages tu.

ADD TO HOME SCREEN
  iPhone : buka di Safari > Share > Add to Home Screen
  Android: buka di Chrome > menu ⋮ > Add to Home screen / Install app
  Bila dibuka dari home screen, takde address bar dan takde double-tap zoom.
